# Luca Mittino Portfolio

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Create a public GitHub repository named lucamittin00-dev.github.io.
3. Upload the extracted contents, including assets and code. Keep index.html at the repository root. Do not upload the ZIP itself.
4. Include the empty .nojekyll file. If your file browser hides it, create it directly on GitHub using Add file > Create new file.
5. In Settings > Pages, select Deploy from a branch, main, and / (root), then Save.
6. When deployment finishes, open https://lucamittin00-dev.github.io/.

GitHub Pages makes this website public. The Python file is a source-code download and is not executed by the website.
